# RENTORA - Peer-to-Peer Rental Marketplace

RENTORA is a modern web application designed to facilitate the renting of everyday items. It provides a seamless platform for users to both list their unused items for rent and find specific items they need for short-term use, promoting a sustainable and community-driven sharing economy.

## Current Status
The project is currently in active development. The frontend user interface has been completely structured and designed, including the core navigation, authentication layouts, search interfaces, and item listing forms.

## Features Implemented
* **Dynamic Hero Section:** A conversion-focused landing area with an integrated search bar and category quick-links.
* **Authentication UI:** Seamless single-page login and registration interfaces with intuitive toggles.
* **Advanced Browse Interface:** A robust search results page featuring comprehensive filtering options (category, price, availability, distance) and sorting capabilities.
* **Item Listing Flow:** A structured form for users to transition into "Renter" mode and publish their items with details, pricing, and image placeholders.
* **Scalable Architecture:** Component-based React structure utilizing React Router for seamless navigation.

## Tech Stack
* **Frontend:** React.js, React Router
* **Backend:** Node.js, Express.js (In Progress)
* **Database:** MySQL (In Progress)
* **Authentication:** JWT & bcrypt (Planned)

## Local Development Setup
1. Clone the repository: `git clone https://github.com/SahanMiraj/RENTORA-Web.git`
2. Navigate to the project directory: `cd RENTORA-Web`
3. Install dependencies: `npm install`
4. Start the development server: `npm run dev` (or `npm start`)
